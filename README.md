# Coffeeshop-Kiosk
Kiosk for the Coffee Lover. Start your day with coffee and enjoy your day without any hustle.

This project models a simple self-service kiosk for a coffee shop. Customers use
the kiosk to browse the menu, customize their order, and pay without needing a
cashier. The system generates a unique order confirmation for each purchase and
ensures no two orders are ever assigned the same order number.
